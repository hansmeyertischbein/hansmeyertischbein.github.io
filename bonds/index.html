Formulas

With coupon C per period, face value F, yield y, m payments a year and n periods:

P = Σk=1..n C / (1 + y/m)k + F / (1 + y/m)n

  • Macaulay duration D = Σ tk · PVk / P, in years.
  • Modified duration D* = D / (1 + y/m). A 1 point rise in yield cuts the price by about D* percent.
  • Convexity K = Σ CFk · k(k + 1) / (1 + y/m)k+2 / (P · m²).
  • Price change ΔP/P ≈ −D* · Δy + ½ · K · (Δy)².
  • DV01 = D* · P · 0.0001, the krone change in price per 100 face value for a 0.01 point move.

The calculator assumes settlement on a coupon date, so there is no accrued interest, and a flat yield for all cash flows. Real government bonds trade with accrued interest and are better priced off a zero-coupon curve.
